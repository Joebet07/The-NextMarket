A fair second look.

Our return guidelines for brand-new and pre-loved electronics.

Return eligibility

Buyers may request a return within 7 days of receiving an item if it does not match its description, arrives damaged, or has a hardware defect. Please keep the original box and accessories.

Brand-new items

Returns require the complete device, original accessories, and order reference. Please remove any personal accounts or screen locks before sending back a device.

Pre-loved items

Used devices are checked against their listed condition grade and description. Normal cosmetic wear that was already listed in the description is not considered a defect.

How to request a return

Send us a message on the Contact page with your order reference number and details of the issue. Once approved, we will provide return instructions.
